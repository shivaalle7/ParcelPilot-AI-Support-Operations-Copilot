\# AI Tool Usage



AI coding tools were used during development to accelerate implementation, debugging, documentation, and iteration.



\## Tools Used



\### ChatGPT



Used for:



\- Planning the system architecture

\- Designing the agent workflow

\- Designing the tool interfaces

\- Developing prompts and reasoning flows

\- Debugging Python and Streamlit issues

\- Reviewing implementation decisions

\- Preparing documentation

\- Improving the user interface and user experience



\### Groq / LLM



Used as the language-model layer for:



\- Natural-language understanding

\- Tool selection

\- Multi-step reasoning

\- Generating natural-language responses

\- Summarizing retrieved evidence



\### Python Development Tools



Python-based development tools were used for:



\- Data processing

\- Excel/structured-data handling

\- Document processing

\- Retrieval

\- Agent implementation

\- Streamlit application development



AI-generated suggestions were reviewed, tested, and adapted during implementation rather than being used blindly.
